# Debug-Boards

This repository contains the hardware designs and firmware for our integrated debug board, debug adapter, and flex debug cables.

## 📦 Contents

This repository includes designs for:

*   **Flex debug cable**: Hardware and associated files for the flexible debug cables.
*   **Picoballoon Adapter**: Hardware for the Picoballoon SWD debug adapter.

Each subdirectory contains the relevant schematics, PCB layouts, firmware source, and documentation for that specific debug component.
